# Student Management System (C++)

## Description
A console-based Student Management System built using C++ and Object-Oriented Programming (OOP).  
Supports adding, updating, searching, and displaying student records efficiently.

## Features
- Add new student records
- Update existing student details
- Search for students by name or ID
- Display all students in the system
- Demonstrates OOP concepts: classes, objects, inheritance, encapsulation

## Tech Stack
- C++ (OOP)
- Standard Template Library (STL)
